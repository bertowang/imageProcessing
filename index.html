本书的主张

传统算法把先验写成公式，AI 算法把先验交给数据。两者不是替代关系：数据增强、退化建模、几何约束、评价指标、后处理全部来自上卷，而语义鸿沟与可训练表示是下卷要解决的问题。

上卷的学习闭环固定为四步：读公式 → 跑代码 → 改参数 → 写结论；下卷的闭环是读原理 → 跑官方示例 → 换数据集/骨干 → 写消融表。

运行 Octave 示例（30 秒）

  1. 安装 GNU Octave（macOS 可用 brew install octave，Linux 用包管理器，Windows 有安装包）。
  2. 在任意上卷章节的「Octave 实例」里点代码块右上角的「复制」，保存为 .m；或直接使用仓库里同名的 code/*.m 文件——它们由 tools/extract_code.py 从 HTML 自动抽取，永远与页面一致。
  3. 命令行运行：octave --no-gui --quiet part1/03-gray-transform/code/03-histeq.m。
  4. 批量验证全部示例：IP_HEADLESS=1 ./tools/run_octave.sh——不弹图形窗口，只检查每个脚本能否正常结束并打印数值。
给程序员的代码契约
  • 零依赖：只用 Octave 核心函数，不调用 image 包的 imfilter/edge/imresize，算法主体全部展开。
  • 自包含：用 meshgrid 合成测试图像，不依赖任何外部图片素材。
  • 参数集中：脚本开头的「参数区」集中所有可调量，先改这里。
  • 数值可核对：结尾 printf 打印可手算的量，页面给出预期值。
  • 可批量验证：IP_HEADLESS=1 时跳过绘图。

学习路线（建议两个学期）

  1. 阶段 A · 打好共同语言（卷首 00～02）：Octave 环境、图像即矩阵、卷积与边界、质量评价。目标：能自己造测试图并预测滤波结果。
  2. 阶段 B · 上卷前段：变换与复原（03～08）：灰度变换、空域/频域滤波、维纳复原、几何变换、彩色处理。目标：每章能解释参数对输出数值的影响。
  3. 阶段 C · 上卷后段：结构与理解（09～15）：形态学、边缘、特征、分割、描述、压缩，最后完成一条可交付的颗粒计数流水线。
  4. 阶段 D · 下卷：从基线到系统（16～26）：传统机器学习基线 → CNN 与骨干 → 数据集与评测 → 分类/检测/分割/复原/生成/基础模型 → 部署与综合项目。目标：能复现官方工程，并完成与传统基线的定量对比。

时间有限时的最短路径：01 → 02 → 04 → 05 → 15 → 17 → 19 → 26。
