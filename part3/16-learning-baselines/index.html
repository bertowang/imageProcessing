§16.1把局部特征汇成全局向量

第 11、13 章给出的 SIFT、LBP、Hu 矩是局部或单个目标的描述，而分类需要整幅图一个定长向量。经典做法是视觉词袋（BoVW）：

  1. 从训练图提取大量局部描述子，k-means 聚成 K 个“视觉单词”（码本）。
  2. 每张图的描述子量化到最近单词，统计词频直方图（常加 TF-IDF 加权）。
  3. 用直方图训练分类器。

VLAD 记录每个描述子相对聚类中心的残差之和，Fisher Vector 用高斯混合模型的梯度表示，二者保留了比词频更丰富的信息，在深度学习普及前是图像检索与分类的 SOTA。

§16.2分类器与偏差-方差

分类器假设何时用
SVM（RBF 核）存在最大间隔超平面样本不多、特征维度中等；需调 C 与 γ
随机森林特征可轴对齐划分混合类型特征、需要特征重要度、抗过拟合
kNN同类样本在特征空间邻近作为最简单基线；高维时距离失效
Logistic 回归线性可分必须有的下限基线，训练极快

模型复杂度与泛化误差的关系仍是偏差-方差分解：容量太小欠拟合，太大过拟合，正则化与交叉验证是在两者间找位置。类别不平衡时要改看 PR 曲线、F1 与每类召回，而不是只看总体准确率。

§16.3为什么必须走向表示学习

  • 语义鸿沟：像素/梯度统计与“这是一只猫”之间没有可写的映射规则。
  • 特征不可训练：BoVW 的码本、SIFT 的描述子都是人定的，任务一变就得重新设计。
  • 维度灾难：手工拼接的高维特征在有限样本下距离度量失效。
  • 端到端：让特征提取器与分类器一起由损失驱动优化，是 CNN 最本质的改变。

工程建议：即使最终要用深度网络，也先花半小时跑一个 HoG/LBP + 线性 SVM 的传统基线。它给出了下限、暴露了数据问题，并让后续提升可归因——这正是第 26 章综合项目的要求。

§常见误区

  • 跳过传统基线直接上深度模型：无法判断提升来自模型还是来自数据清洗。
  • 在测试集上做 k-means 码本或特征选择：数据泄漏，指标虚高。
  • 用准确率评价 1:99 的不平衡数据：全预测多数类就有 99%。
  • 把高维手工特征直接喂 kNN：距离集中，分类接近随机。
