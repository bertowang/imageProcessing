§14.1冗余与信息论下限

图像可压缩是因为三类冗余：编码冗余（灰度值出现概率不均）、像素间冗余（相邻像素高度相关）、心理视觉冗余（人眼对高频与色度不敏感，可以丢弃）。一阶熵给出无损编码的平均码长下界：

H = −Σ_k p(k)·log₂ p(k)　（bit / 像素）

率失真框架把有损压缩写成“在给定码率 R 下最小化失真 D”：量化步长越大，D 越大、R 越小。JPEG 的 quality 参数本质就是在调这张量化表的整体缩放。

§14.2JPEG 全流程

  1. 色彩空间转换与色度下采样：RGB → YCbCr，Cb/Cr 常按 4:2:0 降采样（第 08 章）。
  2. 分块 8×8 + 电平移位：每个分量切成 8×8 块。
  3. DCT：D = T·B·Tᵀ，T 是正交 DCT 矩阵；能量集中到左上角低频，直流系数 D(1,1) 正比于块均值。
  4. 量化：Dq = round(D ./ Q)，Q 在高频取更大值，使多数高频系数变成 0。
  5. Zigzag + 游程 + Huffman：把二维系数按低频到高频拉成一维，长串 0 用 RLE，最后熵编码。

解码是反量化 + 逆 DCT（B̂ = Tᵀ·Dq·Q·T）+ 拼接。块效应来自各块独立量化后边界不连续，振铃来自高频被硬性截掉；JPEG2000 用小波做全图多分辨率变换，避免 8×8 分块，低码率下明显更干净但计算更重。

§Octave 实例

手写 8×8 DCT + 量化 + 反变换的完整 JPEG 内核

%% 14-dct-jpeg.m | DCT 矩阵 / 量化表 / 零系数比例 / PSNR
%% GNU Octave，零第三方依赖；合成图像，无需任何外部文件
clear; close all; clc;
SHOW = ~strcmp(getenv("IP_HEADLESS"), "1");
% ---- 参数区 ----
N = 128; bs = 8; qscale = 2.0;      % qscale 越大压缩越狠
% ---- 造图：方块 + 渐变 + 细纹理 ----
[X, Y] = meshgrid(1:N, 1:N);
f = 0.30 + 0.35*(X/N) + 0.20*double(X>40 & X<80 & Y>40 & Y<80);
f = min(max(f + 0.05*sin(X/2).*sin(Y/2), 0), 1);
% ---- 算法 1：构造 8x8 正交 DCT 矩阵 ----
T = zeros(bs, bs);
for u = 0:bs-1
  for x = 0:bs-1
    T(u+1, x+1) = sqrt((1 + double(u>0)) / bs) * cos(pi*(2*x+1)*u/(2*bs));
  end
end
% ---- 算法 2：标准亮度量化表（近似）----
Q = [16 11 10 16 24 40 51 61; 12 12 14 19 26 58 60 55;
     14 13 16 24 40 57 69 56; 14 17 22 29 51 87 80 62;
     18 22 37 56 68 109 103 77; 24 35 55 64 81 104 113 92;
     49 64 78 87 103 121 120 101; 72 92 95 98 112 100 103 99];
Qs = Q * qscale;
% ---- 算法 3：逐块 DCT -> 量化 -> 反量化 -> IDCT ----
out = zeros(N, N); nzero = 0; ncoef = 0; dc_energy = 0; all_energy = 0;
for r = 1:bs:N
  for c = 1:bs:N
    blk = f(r:r+bs-1, c:c+bs-1);
    D = T * blk * T';
    Dq = round(D ./ Qs);
    nzero = nzero + sum(Dq(:) == 0); ncoef = ncoef + bs*bs;
    dc_energy = dc_energy + D(1,1)^2; all_energy = all_energy + sum(D(:).^2);
    out(r:r+bs-1, c:c+bs-1) = T' * (Dq .* Qs) * T;
  end
end
% ---- 数值验证 ----
printf("T 正交性误差 |T*T'-I| = %.3e\n", max(abs((T*T' - eye(bs))(:))));
printf("直流能量占块内总能量 = %.4f（能量集中在低频）\n", dc_energy / all_energy);
printf("量化后零系数比例 = %.4f（qscale=%.1f）\n", nzero/ncoef, qscale);
printf("重建 MSE = %.6f, PSNR = %.2f dB\n", ...
       mean((f(:)-out(:)).^2), 10*log10(1/mean((f(:)-out(:)).^2)));
printf("重建灰度范围 = [%.3f, %.3f]（可能出现轻微越界）\n", min(out(:)), max(out(:)));
printf("提示：把 qscale 改成 0.5 / 8，观察零系数比例与 PSNR 的反向变化\n");
% ---- 可视化 ----
if SHOW
  figure("name", "14 JPEG 内核");
  subplot(1, 3, 1); imagesc(f, [0 1]); colormap gray; axis image off; title("原图");
  subplot(1, 3, 2); imagesc(min(max(out,0),1), [0 1]); axis image off; title("重建图");
  subplot(1, 3, 3); imagesc(abs(f - out)*5); axis image off; title("误差 x5（块效应）");
end

操作：运行后把 <code>qscale</code> 改成 0.5 / 8，记录零系数比例与 PSNR；在误差图里找 8×8 的块边界。　预期与判读：<code>T·Tᵀ=I</code> 误差在机器精度内；直流系数占了块能量的绝大部分；qscale 越大零系数越多、PSNR 越低；误差图会显出 8×8 方块网格，即块效应。　文件位置：part2/14-compression/code/14-dct-jpeg.m

§常见误区

  • 用 <code>T'·D·T</code> 之外的顺序做逆 DCT：转置位置写反会得到转置的错误重建。
  • 量化后忘记乘回 <code>Q</code> 就做逆变换：重建图几乎全黑。
  • 只报 PSNR 不看误差图：低码率下块效应明显但 PSNR 未必很差。
  • 对色度通道用亮度量化表：人眼敏感度不同，标准里两张表并不相同。

§习题与思考

  1. 推导 <code>D(1,1) = 8·块均值</code>（电平移位后），并用 14-dct-jpeg.m 的数值验证。
  2. 把量化表 Q 改成全 1（等价不做量化但保留取整），观察 PSNR 与零系数比例，说明取整本身带来多少误差。
