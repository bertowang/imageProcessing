§11.1角点与 Harris 响应

在局部窗口里平移 [u,v]，用自相关矩阵 M = Σ w·[Iₓ² IₓI_y; IₓI_y I_y²] 描述灰度变化。M 的两个特征值：都小 = 平坦区；一大一小 = 边缘；都大 = 角点。为避免算特征值，Harris 用：

R = det(M) − k·trace(M)²，　det = λ₁λ₂，　trace = λ₁ + λ₂

k 常取 0.04～0.06；R > 0 且局部极大判为角点。Shi-Tomasi 直接用 min(λ₁,λ₂)，在跟踪任务里更稳定。角点响应对旋转与光照线性变化不变，但对尺度不变——这是 SIFT 要解决的问题。

§11.2SIFT 与工程取舍

  1. 尺度空间极值：用 DoG 金字塔在 (x,y,σ) 三维里找局部极值，得到尺度不变的关键点位置。
  2. 主方向：统计邻域梯度方向直方图，取峰值方向并把坐标系旋转对齐，获得旋转不变性。
  3. 描述子：把 16×16 邻域分成 4×4 子块，每块统计 8 个方向，得 128 维向量；再做光照归一化。
特征描述子速度适合
SIFT128 维浮点慢高精度配准、三维重建、教学基准
SURF64 维浮点中SIFT 的积分图加速版
ORB256 bit 二值快SLAM、移动端实时匹配（汉明距离）

§11.3匹配、比值测试与 RANSAC

最近邻匹配必然产生错误对应。比值测试：只有当“最近距离 / 次近距离 < 0.7～0.8”才接受，因为重复纹理会让两个候选距离接近。RANSAC：随机抽最小样本（仿射 3 对、单应 4 对）估计模型，统计内点数，重复取最优，最后用全部内点重估。它能容忍相当比例的外点，是几何估计的标准做法（第 07 章配准就靠它）。

§11.4Hough 变换

直线用极坐标 ρ = x·cosθ + y·sinθ 参数化。每个边缘点对一组 (θ, ρ) 投票，累加器峰值就是共线点最多的参数组合。优点是对断裂、遮挡与孤立噪点鲁棒；代价是内存与时间随参数维度增长，圆检测（3 维）已明显变贵，广义 Hough 更复杂。

现代做法常用“分割网络输出边缘图 → 概率 Hough 或 RANSAC 拟合”的组合：上卷提供几何约束，下卷提供更好的边缘图，见第 22、26 章。

§Octave 实例

手写 Harris 角点响应与非极大抑制

%% 11-harris.m | 自相关矩阵 / Harris 响应 / 角点定位
%% GNU Octave，零第三方依赖；合成图像，无需任何外部文件
clear; close all; clc;
SHOW = ~strcmp(getenv("IP_HEADLESS"), "1");
% ---- 参数区 ----
N = 96; k = 0.05; thresh = 0.005;
% ---- 造图：一个矩形（4 个直角）+ 一个圆盘（无角点）----
[X, Y] = meshgrid(1:N, 1:N);
f = 0.15 + 0.65*double(X>20 & X<45 & Y>20 & Y<45);
f = f + 0.5*double((X-70).^2 + (Y-65).^2 < 15^2);
f = min(max(f, 0), 1);
% ---- 算法：梯度 -> M 的三个分量 -> R = det - k*trace^2 ----
Gx = [-1 0 1]; Gy = Gx';
dx = conv2(f, Gx, "same"); dy = conv2(f, Gy, "same");
w = ones(5,5)/25;
A = conv2(dx.^2, w, "same");
B = conv2(dy.^2, w, "same");
C = conv2(dx.*dy, w, "same");
R = A.*B - C.^2 - k*(A + B).^2;
% ---- 非极大抑制（3x3）----
% 手写 3x3 非极大抑制，不依赖 image 包
% 手写等价实现（始终有效，覆盖上一行结果）
p = 1; rp = zeros(N+2, N+2); rp(2:N+1, 2:N+1) = R;
peak = zeros(N, N);
for r = 1:N
  for c = 1:N
    blk = rp(r:r+2, c:c+2);
    peak(r,c) = double(R(r,c) == max(blk(:)) && R(r,c) > thresh);
  end
end
[rr, cc] = find(peak);
% ---- 数值验证 ----
printf("Harris 响应: min=%.6f max=%.6f\n", min(R(:)), max(R(:)));
printf("平坦区响应 (5,5) = %.6f, 边缘响应 (30,20) = %.6f\n", R(5,5), R(30,20));
printf("检测到的角点数 = %d（矩形约 4 个）\n", numel(rr));
printf("前几个角点坐标 (行,列): ");
for t = 1:min(6, numel(rr)), printf("(%d,%d) ", rr(t), cc(t)); end
printf("\n");
% ---- 可视化 ----
if SHOW
  figure("name", "11 Harris 角点"); imagesc(f, [0 1]); colormap gray; axis image off;
  hold on; plot(cc, rr, "r+", "markersize", 12); hold off; title("角点响应峰值");
end

操作：运行后把 <code>k</code> 改成 0.15、<code>thresh</code> 改成 0.001，观察角点数变化。　预期与判读：响应在平坦区接近 0、边缘处为负或较小、角点处显著为正；矩形附近出现约 4 个峰值，圆盘没有明显角点；k 越大越倾向于只保留强角点。　文件位置：part2/11-features/code/11-harris.m

§常见误区

  • Harris 直接使用 <code>dx.^2</code> 不做窗口聚合：响应充满噪声，找不到稳定峰值。
  • 以为 Harris 对尺度不变：图像放大后角点可能消失，需要 SIFT 的尺度空间。
  • 匹配时只用最近邻不做比值测试：重复纹理区域产生大量错误对应。
  • Hough 的 ρ 出现负值直接丢弃：应允许负 ρ 或把 θ 范围取满 [0,π)。
