§12.1阈值与 Otsu

阈值分割假设直方图是双峰：目标与背景各占一峰。Otsu 不依赖人工选阈值，而是遍历所有候选 t，最大化类间方差：

σ_B²(t) = w₀(t)·w₁(t)·[ μ₀(t) − μ₁(t) ]²

等价于最小化类内方差。它只需直方图，复杂度 O(L)（L 为灰度级数），非常快；但光照不均、目标占比极小、直方图单峰时会失效。此时改用自适应阈值：每个像素用局部窗口的统计量算自己的阈值（如局部均值减常数 C）。

§12.2区域、聚类与形态学后处理

  • 区域生长：从种子出发，把满足相似性（灰度差、颜色距离）的邻像素并进来；关键是种子与停止准则。
  • 分水岭：第 09 章的距离变换 + 标记控制流程，特别适合粘连圆形目标。
  • k-means 聚类：把每个像素看作特征向量（灰度、RGB、Lab，或加上位置），迭代更新类中心与归属；对初值敏感、需指定 K。
  • 后处理：开运算去噪点、闭运算填孔、连通域面积筛选、边界平滑——工业流水线里这一步往往比换分割算法更有效。

无论用哪种方法，输出都应是逻辑掩模（整数标签），后续插值/缩放只能用最近邻，见第 07 章。

§12.3能量最小化：图割与活动轮廓（研究生）

把分割写成给每个像素赋标签的能量最小化问题：

E(L) = Σ_p D_p(L_p) + λ Σ_(p,q) V(L_p, L_q)

数据项 D 描述像素像不像某类（可由颜色直方图建模），平滑项 V 惩罚相邻像素标签不同（常用 Potts 模型）。当 V 是次模函数时，二值分割可用图割 / 最大流最小割求全局最优；这也是 GrabCut 交互式分割的核心。

活动轮廓（snake）则把边界参数化为曲线，最小化内部弹性能 + 图像梯度吸引能 + 外部约束；水平集把曲线嵌入高一维函数的零水平集，从而自然处理拓扑变化（分裂/合并）。二者优化的是连续几何，与图割的离散标签视角互补。这一支“可优化的能量模型”正是下卷用损失函数 + 反向传播取代的对象。

§Octave 实例

手写 Otsu：遍历 256 个阈值的类间方差

%% 12-otsu.m | 直方图 / 类间方差 / 自动阈值 / 误分率
%% GNU Octave，零第三方依赖；合成图像，无需任何外部文件
clear; close all; clc;
SHOW = ~strcmp(getenv("IP_HEADLESS"), "1");
% ---- 参数区 ----
N = 128; bins = 256; bg = 0.25; fg = 0.75; noise_sigma = 0.06;
randn("seed", 81);
% ---- 造图：亮目标 + 暗背景 + 高斯噪声 ----
[X, Y] = meshgrid(1:N, 1:N);
truth = double((X-64).^2 + (Y-64).^2 < 30^2);
f = bg + (fg-bg)*truth + noise_sigma*randn(N,N);
f = min(max(f, 0), 1);
% ---- 算法：直方图 -> 遍历阈值 -> 最大类间方差 ----
q = round(f(:)*(bins-1)) + 1;
h = zeros(bins,1);
for i = 1:numel(q), h(q(i)) = h(q(i)) + 1; end
total = numel(q); levels = (0:bins-1)' / (bins-1);
best_var = -1; best_t = 1;
for t = 2:bins
  w0 = sum(h(1:t-1)) / total; w1 = 1 - w0;
  if w0 == 0 || w1 == 0, continue; end
  m0 = sum(levels(1:t-1) .* h(1:t-1)) / sum(h(1:t-1));
  m1 = sum(levels(t:bins) .* h(t:bins)) / sum(h(t:bins));
  v = w0 * w1 * (m0 - m1)^2;
  if v > best_var, best_var = v; best_t = t; end
end
T = levels(best_t);
seg = f > T;
% ---- 数值验证 ----
printf("直方图总和 = %d, 像素总数 = %d\n", sum(h), total);
printf("Otsu 阈值 = %.4f（理论中点在 (%.2f+%.2f)/2 = %.2f）\n", T, bg, fg, (bg+fg)/2);
printf("最大类间方差 = %.6f\n", best_var);
printf("前景占比 = %.4f（真值 %.4f）\n", mean(seg(:)), mean(truth(:)));
printf("误分率 = %.4f%%\n", 100*mean(seg(:) ~= truth(:)));
printf("把噪声提高到 0.20 后误分率会明显上升，可自行验证\n");
% ---- 可视化 ----
if SHOW
  figure("name", "12 Otsu 分割");
  subplot(1, 3, 1); imagesc(f, [0 1]); colormap gray; axis image off; title("加噪图");
  subplot(1, 3, 2); bar(h); xlim([0 bins]); title("双峰直方图");
  subplot(1, 3, 3); imagesc(seg, [0 1]); axis image off; title("Otsu 掩模");
end

操作：运行后把 <code>noise_sigma</code> 改成 0.20、把前景面积缩小到半径 10，分别记录阈值与误分率。　预期与判读：直方图总和等于像素数；阈值应落在 0.5 附近（两峰中点）；最大类间方差约 0.06 量级；噪声变大或目标占比极小时，阈值偏移、误分率上升。　文件位置：part2/12-segmentation/code/12-otsu.m

手写 k-means 灰度聚类与收敛过程

%% 12-kmeans-seg.m | 1D 特征空间聚类 / 迭代收敛 / 标签图
%% GNU Octave，零第三方依赖；合成图像，无需任何外部文件
clear; close all; clc;
SHOW = ~strcmp(getenv("IP_HEADLESS"), "1");
% ---- 参数区 ----
N = 96; K = 3; max_iter = 30;
% ---- 造图：三级灰度的同心方环 + 轻微噪声 ----
[X, Y] = meshgrid(1:N, 1:N); randn("seed", 82);
d = max(abs(X-N/2), abs(Y-N/2));
f = 0.20*double(d > 30) + 0.50*double(d > 15 & d <= 30) + 0.85*double(d <= 15);
f = min(max(f + 0.02*randn(N,N), 0), 1);
% ---- 算法：交替更新归属与类中心 ----
data = f(:); centers = [0.15; 0.50; 0.90];
for it = 1:max_iter
  dist = abs(data - centers');       % 自动广播成 numel(data) x K
  [~, idx] = min(dist, [], 2);
  new_centers = centers;
  for k = 1:K
    if any(idx == k), new_centers(k) = mean(data(idx == k)); end
  end
  shift = max(abs(new_centers - centers));
  centers = new_centers;
  if shift < 1e-6, break; end
end
seg = reshape(idx, N, N);
% ---- 数值验证 ----
printf("真值灰度级: 0.20 / 0.70 / 0.85\n");
printf("收敛迭代数 = %d, 最终中心位移 = %.3e\n", it, shift);
printf("学到的类中心: "); printf("%.4f ", centers); printf("\n");
printf("各类像素数: "); printf("%d ", arrayfun(@(k) sum(idx==k), 1:K)); printf("\n");
printf("类内平方和 = %.4f\n", sum((data - centers(idx)).^2));
% ---- 可视化 ----
if SHOW
  figure("name", "12 k-means");
  subplot(1, 2, 1); imagesc(f, [0 1]); colormap gray; axis image off; title("原图");
  subplot(1, 2, 2); imagesc(seg); axis image off; title("聚类标签图");
end

操作：运行后把 <code>centers</code> 初值改成 <code>[0.1;0.2;0.3]</code>，观察是否收敛到同一解；把 K 改成 4。　预期与判读：迭代通常在十几步内收敛，中心接近三级真实灰度；类内平方和随 K 增大而下降（但 K 过大会把噪声也聚成一类）；初值不同可能得到不同局部最优。　文件位置：part2/12-segmentation/code/12-kmeans-seg.m

§常见误区

  • 对光照不均的图用全局 Otsu：一侧背景被整片误判为目标，需自适应阈值或先做光照校正。
  • 把 K 当成可以随便调大的参数：K 越大类内误差越小，但不代表分割更有意义。
  • 对掩模做双线性缩放：会生成不存在的标签值（第 07 章）。
  • 省略形态学与面积筛选：孤立噪点会让连通域计数完全失真。

§习题与思考

  1. 从类内方差最小出发，推导它与 Otsu 类间方差最大等价。
