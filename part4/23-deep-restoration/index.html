§23.1从上卷到这里的同一条公式

第 06 章的退化模型 g = h∗f + n 依然成立，维纳滤波用功率谱比作为先验；深度方法把先验换成一个由数据学出的网络 f̂ = R_θ(g)，训练目标是最小化重建误差或感知距离。区别在于：维纳的先验是人写死的平稳性假设，网络的先验是训练图像分布的统计规律。因此网络在训练分布外（新传感器、新噪声类型）同样会失效，只是失效方式更难解释。

§23.2去噪与超分的代表性结构

任务模型要点
高斯去噪DnCNN / FFDNet预测噪声残差而非干净图；批归一化 + 残差学习；FFDNet 把噪声水平图一起输入，一个模型覆盖多噪声强度
超分SRCNN → EDSR从三层卷积到去掉 BN 的深残差网络，优化 PSNR
感知超分SRGAN / ESRGAN加入对抗损失与 VGG 感知损失，生成更锐利的纹理
真实退化Real-ESRGAN用高阶退化建模（模糊、下采样、噪声、压缩多次叠加）合成训练对

关键矛盾：像素级损失（L1/MSE）会给出高 PSNR 但过度平滑的结果；对抗/感知损失视觉更锐利，却可能 hallucinate 出原本不存在的纹理。医学影像、遥感测量等场景必须优先保真，不能用感知导向模型直接出定量结论。

§23.3评价与落地

  • 有配对真值：PSNR / SSIM；无配对真实退化：无参考指标 + 人工评分 + 下游任务指标。
  • 务必在真实退化数据上验证：只用双三次下采样合成的测试集，会系统性高估泛化能力。
  • 与第 06 章的维纳滤波做对照实验：记录 PSNR、运行时间与“过度平滑”的主观评价。

这一章是上下卷结合最紧的地方：先用第 06 章的公式判断退化类型，再决定用维纳这样的可解释线性方法，还是用学习先验。工程上常把两者串联——传统方法做确定性校正，网络只学残差。

§常见误区

  • 只报 PSNR 就说“更清晰”：感知导向模型常 PSNR 更低但视觉更好。
  • 只在双三次下采样测试集上评价超分：与真实退化差距很大。
  • 在医学/测量场景使用生成式超分：可能凭空生成纹理，影响诊断或计量。
  • 忽略噪声水平：非盲模型在训练范围外的噪声强度上会明显退化。
