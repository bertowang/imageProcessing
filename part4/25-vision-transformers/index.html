§25.1ViT：把图像当词序列

把图像切成固定大小 patch（如 16×16），每个 patch 线性投影成一个 token，加上位置编码与类别 token，送入标准 Transformer 编码器：

Attention(Q,K,V) = softmax(QKᵀ/√d) · V，　token 数 = (H/P)·(W/P)

自注意力是全局、内容自适应的：任意两个 patch 一步就能交互；代价是复杂度随 token 数平方增长（高分辨率图很贵），且缺少 CNN 的局部性与平移等变性这些先验，需要更大规模数据才能学到同等表示。

§25.2效率与自监督

  • Swin：在局部窗口内做注意力，用移位窗口跨窗口交互，得到层级化多尺度特征，可直接接检测/分割头。
  • MAE：随机遮住大部分 patch，让模型重建被遮内容，用重建目标学表示。
  • DINOv2：自蒸馏式的自监督，产出无需微调就很好用的通用冻结特征，适合迁移到专业域（第 18 章）。

自监督的意义在于：标注昂贵而无标注图像海量。它把“先预训练再迁移”从 ImageNet 标签中解放出来。

§25.3图文对齐与基础模型

CLIP 用对比学习把图像编码器与文本编码器对齐到同一空间，于是分类可以写成“图像与哪个文本提示最相似”，得到零样本分类与开放词表能力（第 21 章的 GroundingDINO 就建立在这类对齐之上）。视觉语言模型（LLaVA 等）进一步把视觉 token 接进大语言模型，实现读图问答与推理。

迁移方式改什么成本
提示工程只改文本提示 / 示例最低，先做这个
Adapter / 线性探针冻结骨干，训练小模块低，适合小样本
LoRA / 部分微调低秩增量或后几层中，适合领域适配

§常见误区

  • 把 ViT 直接用于高分辨率密集任务：token 数平方增长会爆显存。
  • 小数据集从头训 ViT：缺少归纳偏置，通常不如预训练 CNN。
  • 把 CLIP 零样本分数当校准概率：文本提示措辞会显著影响结果。
  • 忽略基础模型的训练数据偏差：下游可能放大特定人群/场景的误差。

§习题与思考

  1. 计算 <code>224×224</code> 输入、<code>16×16</code> patch 的 token 数，并估算自注意力矩阵的元素数。
  2. 比较 MAE 与 DINOv2 的自监督目标，说明为什么二者学出的特征用途不同。
