§24.1VAE：把图像压进一个分布

自编码器把图像压成低维向量再重建，只能做插值，不能保证潜在空间连续可采样。VAE 让编码器输出分布参数 (μ, σ)，用重参数化技巧 z = μ + σ·ε 使采样可导，优化证据下界：

L = E_q[log p(x|z)] − KL( q(z|x) ‖ p(z) )

第一项是重建质量，第二项把潜在分布拉向标准正态。VAE 采样稳定、覆盖模式较全，但结果常偏模糊。

§24.2GAN 与图像翻译

min_G max_D E_x[log D(x)] + E_z[log(1 − D(G(z)))]

生成器与判别器做极小极大博弈，判别器逼生成器逼近真实图像分布。优势是样本锐利，代价是训练不稳定、模式崩塌（只生成少数几类）与难以覆盖全分布。

  • pix2pix：需要成对数据的条件图像翻译（边缘图 → 照片、掩模 → 立面）。
  • CycleGAN：用循环一致性约束处理非配对数据（马 ↔ 斑马、风格迁移）。
  • StyleGAN：把风格注入生成器的不同层级，得到可解释、可编辑的潜在方向。

§24.3扩散模型

  1. 前向：按固定方差表逐步给图像加高斯噪声，直到接近纯噪声；任意时刻 x_t 有闭式表达。
  2. 反向：训练一个去噪网络预测所加噪声，从 x_T 逐步还原 x_0。
  3. 潜空间扩散（LDM）：先用 VAE 把图像压到低维潜空间再做扩散，算力骤降，这就是 Stable Diffusion 的核心。
  4. 条件与引导：文本、边缘、深度图等条件 + classifier-free guidance 控制“贴合提示”与“多样性”的权衡。

扩散模型训练稳定、覆盖度好，已成为图像生成与编辑的主流；采样慢是主要工程代价，需要蒸馏或更少步数的采样器。

§24.4评测与伦理

FID 比较生成分布与真实分布在 Inception 特征空间的均值/协方差，CLIP Score 衡量图文对齐；二者都不等于“好看”，也都不能检测记忆化（把训练图背出来）。落地前必须考虑：训练数据版权、生成内容的标识、偏见放大、以及在医学/司法等场景误用合成图像的风险。

§常见误区

  • 把 FID 数值跨论文直接比较：采样量与特征网络可能不同。
  • 忽视模式崩塌：GAN 生成的样本很锐利，但可能只覆盖少数模式。
  • 在需要保真的场景用生成式模型：细节可能是“编”出来的（第 23 章）。
  • 不检查训练数据与权重许可：生成模型的版权风险高于判别模型。
