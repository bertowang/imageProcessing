§A.5常见错误与调试清单

  1. 下标越界 / 尺寸不匹配：先 whos 看维度；conv2(...,"valid") 会缩小输出。
  2. 全白或全黑：检查是否忘了 min(max(a,0),1)，以及 imagesc(a,[0 1]) 的固定范围。
  3. uint8 饱和：所有运算前先 double(a)/255。
  4. 结果整体偏移：频域忘了 fftshift/ifftshift 配对；或核尺寸为偶数。
  5. 滤波后边缘发暗：补零边界导致，改用 replicate / symmetric 填充。
  6. 几何变换镜像/转置：(r,c) 与 (x,y) 顺序写反。
  7. 两次运行结果不同：没有固定 rand/randn 种子。
  8. 掩模出现小数标签：对整数标签图用了双线性插值。
  9. headless 报错：设 IP_HEADLESS=1 跳过绘图；或检查 Octave 图形后端。

§Octave 实例

新建实验的最小模板（复制后改参数区与算法段）

%% A-template.m | 本书所有 Octave 示例的模板
%% GNU Octave，零第三方依赖；合成图像，无需任何外部文件
clear; close all; clc;
SHOW = ~strcmp(getenv("IP_HEADLESS"), "1");
% ---- 参数区：所有可调量集中在这里 ----
N = 128; sigma = 0.05; randn("seed", 1);
% ---- 造图 ----
[X, Y] = meshgrid(1:N, 1:N);
f = 0.30 + 0.50*double((X-N/2).^2 + (Y-N/2).^2 < (N/5)^2);
g = min(max(f + sigma*randn(N,N), 0), 1);
% ---- 算法 ----
w = ones(3,3)/9;
out = conv2(g, w, "same");
% ---- 数值验证：打印可手算核对的量 ----
printf("尺寸 %d x %d, 均值 %.4f -> %.4f\n", rows(f), columns(f), mean(g(:)), mean(out(:)));
printf("MSE(加噪) = %.6f, MSE(平滑) = %.6f\n", ...
       mean((g(:)-f(:)).^2), mean((out(:)-f(:)).^2));
% ---- 可视化：IP_HEADLESS=1 时自动跳过 ----
if SHOW
  figure("name", "模板");
  subplot(1, 2, 1); imagesc(g, [0 1]); colormap gray; axis image off; title("输入");
  subplot(1, 2, 2); imagesc(out, [0 1]); axis image off; title("输出");
end

操作：以此文件为起点新建实验：只改参数区与算法段，保留数值验证与 headless 开关。　预期与判读：平滑后均值基本不变（核和为 1）、MSE 下降；设置 <code>IP_HEADLESS=1</code> 时不弹窗但数值照常打印。　文件位置：appendix/code/A-template.m

代码块右上角可一键复制；本仓库 code/*.m 由 tools/extract_code.py 从这些代码块自动抽取，页面与脚本永远一致。脚本只用 Octave 核心函数，设 IP_HEADLESS=1 可跳过绘图。
