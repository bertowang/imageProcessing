§1.1安装与两种运行方式

GNU Octave 是免费的科学计算环境，语法与 MATLAB 高度兼容，Windows / macOS / Linux 都能装。推荐两种用法：

  • GUI：适合看图和调参数，直接打开文件后按 F5。
  • 命令行：octave --no-gui --quiet code/00-hello-image.m，适合批量跑和写自动化脚本。本书的 tools/run_octave.sh 就用这种方式。
# macOS (Homebrew)            # Ubuntu/Debian              # Windows
brew install octave          sudo apt install octave      # 官网下载安装包 https://octave.org/download
octave --version             octave --eval "disp(2+2)"    # 输出 4 即安装成功

本书示例不要求安装 image 包。若你想用 imshow、imfilter、edge 等现成函数，可执行 pkg install -forge image 并 pkg load image；但书中每个算法都会用核心函数手写一遍，以便看清实现。

§1.2图像 = 矩阵：坐标与类型

类型取值范围典型用途陷阱
uint80～255 整数文件读写、节省内存做加减会饱和截断，uint8(200)+uint8(100) 得 255 而不是 300
double本书统一为 [0,1]滤波、变换、公式推导超过 1 的值用 imagesc(a,[0 1]) 会被裁白，先 min(max(a,0),1)
logical0 / 1掩模、区域、索引与 double 混算前先 double(mask)
M×N×3三个通道RGB 彩色图灰度图没有第三维，size(a,3) 为 1

行列与坐标的对应关系请记牢：f(r,c) 表示第 r 行、第 c 列，几何坐标是 (x,y)=(c,r)。显示时用 axis image 保证纵横比不变，用 colormap gray 保证灰度图不被伪彩染色。

§1.3显示、保存与文件读写

核心的显示三件套是 imagesc + colormap gray + axis image off；imagesc(a,[0 1]) 的第二个参数固定显示范围，避免不同图自动缩放造成视觉误判。

需要读真实照片时，Octave 自带的 imread / imwrite 可以直接用：

a = imread("photo.png");        % 通常是 uint8 MxNx3
g = double(a) / 255;            % 转到本书统一的 [0,1] double
imwrite(uint8(g * 255), "out.png");
printf("size: %d x %d x %d
", size(g,1), size(g,2), size(g,3));

外部图片不可控（光照、压缩、尺寸），所以全书示例一律用合成图：数值可预测、结果可复现、无需附带素材文件。学会造测试图是做算法实验的基本功。

§1.4代码契约与一键验证

每个 .m 脚本都分成五段：参数区 → 造图 → 算法 → 数值验证 → 可视化。可视化被 if SHOW 包住，SHOW 由环境变量 IP_HEADLESS 控制：

# 交互式：看图 + 看数值
octave --no-gui --quiet code/03-histeq.m
# 批量：不弹窗，只检查每个脚本能否正常结束、数值是否打印
IP_HEADLESS=1 ./tools/run_octave.sh
# 只跑某一个脚本
IP_HEADLESS=1 ./tools/run_octave.sh part1/03-gray-transform/code/03-histeq.m

§Octave 实例

数据类型、范围与饱和截断

%% 01-types-and-range.m | uint8 / double / logical 的行为差异
%% GNU Octave，零第三方依赖；合成图像，无需任何外部文件
clear; close all; clc;
SHOW = ~strcmp(getenv("IP_HEADLESS"), "1");
% ---- 参数区 ----
v = 200;
% ---- 算法：观察 uint8 的饱和与 double 的线性 ----
u = uint8(v);
printf("uint8(%d) + uint8(100) = %d  (饱和到 255)\n", v, u + uint8(100));
printf("double(%d)/255 + 0.4   = %.4f\n", v, double(v)/255 + 0.4);
g = (0:255) / 255;                     % 0~1 渐变
clipped = min(max(g * 2, 0), 1);       % 超过 1 的部分必须裁掉
printf("渐变 g: min=%.3f max=%.3f mean=%.4f\n", min(g), max(g), mean(g));
printf("放大 2 倍后未裁剪的比例: %.2f%%\n", 100 * mean(g * 2 > 1));
mask = g > 0.5;
printf("logical 掩模: class=%s 命中 %d / %d\n", class(mask), sum(mask(:)), numel(mask));
printf("掩模均值（double 化后）: %.4f\n", mean(double(mask(:))));
% ---- 可视化 ----
if SHOW
  figure("name", "01 范围与裁剪");
  subplot(1, 2, 1); plot(g * 2); grid on; title("未裁剪：最大值 2"); ylim([0 2.2]);
  subplot(1, 2, 2); plot(clipped); grid on; title("裁剪到 [0,1]"); ylim([0 1.2]);
end

操作：运行后对照四行打印值；把 <code>v</code> 改成 100 再跑一次，看饱和是否还发生。　预期与判读：uint8 相加得 255；double 得约 1.1843；渐变均值 0.5；放大 2 倍后恰好 50% 越界；掩模命中 128/256，均值 0.5。　文件位置：part0/01-octave-setup/code/01-types-and-range.m

合成测试图与噪声注入

%% 01-synthetic-images.m | 阶跃 / 条纹 / 圆盘 + 高斯与椒盐噪声
%% GNU Octave，零第三方依赖；合成图像，无需任何外部文件
clear; close all; clc;
SHOW = ~strcmp(getenv("IP_HEADLESS"), "1");
% ---- 参数区 ----
N = 256; sigma = 0.06; salt_rate = 0.02; rand("seed", 7); randn("seed", 7);
% ---- 造图 ----
[X, Y] = meshgrid(1:N, 1:N);
step  = double(X > N/2);
stripe = 0.5 + 0.35 * sin(2*pi*X/24);
disk  = double((X - 0.5*N).^2 + (Y - 0.5*N).^2 < (0.28*N)^2);
base  = 0.25 + 0.6 * disk;
% ---- 噪声：高斯加性 + 椒盐脉冲 ----
noisy = base + sigma * randn(N, N);
sp = rand(N, N);
noisy(sp < salt_rate/2) = 0;
noisy(sp > 1 - salt_rate/2) = 1;
noisy = min(max(noisy, 0), 1);
% ---- 数值验证 ----
printf("step : mean=%.4f (期望 0.5)\n", mean(step(:)));
printf("stripe: min=%.3f max=%.3f mean=%.4f\n", min(stripe(:)), max(stripe(:)), mean(stripe(:)));
printf("disk : 面积占比=%.4f (pi*0.28^2=%.4f)\n", mean(disk(:)), pi*0.28^2);
printf("noisy: 与干净图的 MSE=%.6f, PSNR=%.2f dB\n", ...
       mean((noisy(:)-base(:)).^2), 10*log10(1/mean((noisy(:)-base(:)).^2)));
% ---- 可视化 ----
if SHOW
  figure("name", "01 合成测试图");
  subplot(2, 2, 1); imagesc(step, [0 1]); colormap gray; axis image off; title("阶跃");
  subplot(2, 2, 2); imagesc(stripe, [0 1]); axis image off; title("正弦条纹");
  subplot(2, 2, 3); imagesc(disk, [0 1]); axis image off; title("圆盘掩模");
  subplot(2, 2, 4); imagesc(noisy, [0 1]); axis image off; title("高斯 + 椒盐噪声");
end

操作：运行脚本；把 <code>sigma</code> 改为 0.02 / 0.15，记录 PSNR 的变化趋势。　预期与判读：阶跃均值 0.5；条纹范围约 0.15～0.85、均值 0.5；圆盘面积占比约 0.2463（π·0.28²）；噪声图的 MSE 与 PSNR 随 sigma 单调变化。　文件位置：part0/01-octave-setup/code/01-synthetic-images.m

代码块右上角可一键复制；本仓库 code/*.m 由 tools/extract_code.py 从这些代码块自动抽取，页面与脚本永远一致。脚本只用 Octave 核心函数，设 IP_HEADLESS=1 可跳过绘图。

§常见误区

  • 对 uint8 直接做加减导致静默饱和：先 <code>double(a)/255</code> 再运算。
  • 显示时不固定范围：<code>imagesc(a,[0 1])</code> 才能跨图比较亮度。
  • 把噪声图的越界值直接显示：<code>min(max(a,0),1)</code> 后再画图与算指标。
  • 忘了 <code>clear</code> 与固定随机种子，导致两次运行结果不同、无法对照。
