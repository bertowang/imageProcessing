§2.1采样、量化与直方图

连续场景经空间采样变成 M×N 网格，再经幅度量化变成有限灰度级。采样决定分辨率与混叠，量化决定位深（8 bit = 256 级）。本书把灰度统一归一化到 [0,1]，因此位深只在读写文件时出现。

直方图 h(k) 统计灰度级 k 的像素数，归一化后是概率质量函数 p(k)=h(k)/(MN)。一阶统计量（均值、方差）描述整体亮度与对比度，但丢掉了空间结构：两张完全不同的图可以有完全相同的直方图，第 05 章的相位实验会把这一点展示得很彻底。

§2.2卷积、相关与边界

线性移不变滤波由卷积定义，g(r,c) = ΣΣ f(r−i,c−j)·w(i,j)；相关只差一个核翻转：g(r,c) = ΣΣ f(r+i,c+j)·w(i,j)。数学卷积要翻转核，图像处理里常把“已翻转好的模板”称为卷积核，于是两者代码一样。本书统一用 conv2，并在注释里写明是否翻转。

g = f ∗ w，　G(u,v) = F(u,v) · H(u,v)
边界策略做法后果
zero / 补零外侧填 0边缘出现暗边，简单且最常用
replicate复制最外圈像素边缘平滑，适合去噪
symmetric镜像反射避免人为边缘，梯度更自然
circular / 周期首尾相接与 DFT 假设一致，频域滤波默认

尺寸约定：conv2(f,w,"same") 返回与 f 同尺寸；"valid" 只保留核完全落在图内的部分，输出会缩小 (k−1)。核尺寸取奇数是为了有明确中心。

§2.3线性移不变系统与点扩散函数

若成像系统满足线性与移不变，它对点光源的响应 h（点扩散函数，PSF）就完整描述了系统：输出是 f∗h。于是“模糊”可以被建模、“去模糊”可以被写成反卷积（第 06 章）。空间域卷积对应频域逐点相乘，这是第 05 章全部内容的起点。

这条链条是上卷的主干：PSF → 卷积 → 频域乘积 → 逆滤波/维纳滤波 → 复原。下卷的超分与去噪网络，本质上仍在学习一个更好的逆映射，只是先验由数据给出而不是由公式给出。

§2.4质量评价：MSE、PSNR 与 SSIM

MSE = (1/MN)Σ(f−ĝ)²,　PSNR = 10·log₁₀(L²/MSE)，本书 L = 1

PSNR 只衡量逐像素误差，对结构错位、模糊、感知质量都不敏感；SSIM 把比较拆成亮度、对比度、结构三项，更接近人眼，但仍不是感知质量的终点（下卷会用 LPIPS、FID 等基于特征的指标）。

评价的铁律：有参考图才能算 PSNR/SSIM；无参考的真实去噪任务只能用噪声估计、人工评分或下游任务指标。数值变好但看起来更糊，通常说明你优化错了目标。

§Octave 实例

手写二维卷积、边界填充与 PSNR

%% 02-conv-and-psnr.m | 二维卷积 / 边界策略 / MSE-PSNR 的一致性
%% GNU Octave，零第三方依赖；合成图像，无需任何外部文件
clear; close all; clc;
SHOW = ~strcmp(getenv("IP_HEADLESS"), "1");
% ---- 参数区 ----
N = 64; noise_sigma = 0.05; k = 3; randn("seed", 11);
% ---- 造图：中心方块 ----
[X, Y] = meshgrid(1:N, 1:N);
f = double(X > N/4 & X < 3*N/4 & Y > N/4 & Y < 3*N/4);
% ---- 算法 1：盒式核 + 补零卷积（与 conv2 对照）----
w = ones(k, k) / (k*k);
g_zero = conv2(f, w, "same");
pad = (k-1)/2;
fp = zeros(N + 2*pad, N + 2*pad);
fp(pad+1:pad+N, pad+1:pad+N) = f;       % zero padding
g_manual = zeros(N, N);
for r = 1:N
  for c = 1:N
    g_manual(r,c) = sum(sum(fp(r:r+k-1, c:c+k-1) .* w));
  end
end
printf("核元素和 = %.6f（应为 1）\n", sum(w(:)));
printf("手写卷积与 conv2 的最大差 = %.3e\n", max(abs(g_manual(:)-g_zero(:))));
% ---- 算法 2：replicate 边界 ----
fr = [repmat(f(1,:), pad, 1); f; repmat(f(end,:), pad, 1)];
fr = [repmat(fr(:,1), 1, pad), fr, repmat(fr(:,end), 1, pad)];
g_rep = conv2(fr, w, "valid");
printf("角落像素 zero=%.4f replicate=%.4f（差异来自边界）\n", g_zero(1,1), g_rep(1,1));
% ---- 算法 3：MSE / PSNR ----
g_noisy = min(max(f + noise_sigma*randn(N,N), 0), 1);
mse = mean((g_noisy(:) - f(:)).^2);
printf("加噪后 MSE=%.6f, PSNR=%.2f dB（理论约 %.2f dB）\n", ...
       mse, 10*log10(1/mse), 10*log10(1/noise_sigma^2));
% ---- 可视化 ----
if SHOW
  figure("name", "02 卷积与边界");
  subplot(1, 3, 1); imagesc(f, [0 1]); colormap gray; axis image off; title("原图");
  subplot(1, 3, 2); imagesc(g_zero, [0 1]); axis image off; title("zero 卷积");
  subplot(1, 3, 3); imagesc(g_rep, [0 1]); axis image off; title("replicate 卷积");
end

操作：运行后重点看第二行数值（应接近机器精度）；把 <code>k</code> 改成 5、<code>noise_sigma</code> 改成 0.1 再跑。　预期与判读：核和为 1；手写循环与 conv2 的最大差约 0（浮点误差）；zero 边界角落更暗；PSNR 约 26 dB，与 10·log10(1/σ²) 一致。　文件位置：part0/02-image-basics/code/02-conv-and-psnr.m

§常见误区

  • 把相关当卷积却忘了翻转核：对称核无差别，非对称梯度核会差一个方向。
  • 用 <code>conv2(...,"valid")</code> 后仍按原尺寸索引，导致维度不匹配。
  • 对 uint8 直接算 MSE：溢出会给出完全错误的结果。
  • 只报 PSNR 不附视觉结果：PSNR 高不代表结构被正确恢复。
