§3.1点运算与四种映射

点运算不含邻域：输出像素只由同一位置的输入像素决定，g = T(f)。因此它不改变空间结构，只改变灰度分布，天然可并行、可用查找表（LUT）实现。

映射公式作用
线性/对比度拉伸g = a·f + b整体提亮或压暗，注意裁剪
对数g = c·log(1+f)压缩高亮动态范围，显示傅里叶频谱
幂律 / gammag = f^γγ<1 提亮暗部，γ>1 压暗；补偿显示器非线性
分段线性折线 T只拉伸感兴趣灰度区间、二值化、灰度切片

工程上注意 T 必须单调（否则灰度次序反转），输出要裁到 [0,1]；对 uint8 图先转 double 再映射。

§3.2直方图均衡化的推导

目标：找一个单调变换 s = T(r)，使输出的灰度分布均匀。连续情形下，概率密度在变换下满足 p_s(s) = p_r(r)·|dr/ds|；取 s = T(r) = ∫₀ʳ p_r(w)dw，即累积分布函数（CDF），则 ds/dr = p_r(r)，代入得 p_s(s)=1。

sₖ = T(rₖ) = Σⱼ₌₀ᵏ p_r(rⱼ) = Σⱼ₌₀ᵏ nⱼ / (MN)

离散实现只有三步：统计直方图 h → 归一化并求 cumsum 得 LUT → 用 LUT 查表映射每个像素。结果不会严格均匀（灰度级有限、同灰度像素必须一起搬移），但会明显展宽动态范围。

§3.3全局均衡的局限与 CLAHE

全局均衡用整幅图的 CDF，会带来三个典型问题：暗区被整体抬亮后噪声被放大、局部细节没有针对性增强、背景占比大时主体反而过曝。

CLAHE（限制对比度自适应直方图均衡）的做法是：把图切成小块（如 8×8），每块单独均衡；均衡前把直方图超过 clip_limit 的部分削峰并均匀再分配，从而限制噪声放大；最后用双线性插值拼接块边界，消除块效应。新增的两个参数（块数、裁剪限幅）都可在第 12 章的分割任务里用下游指标来调。

直方图规定化是另一个方向的推广：不要求输出均匀，而是要求输出匹配指定的直方图。做法是分别求输入与目标的 CDF，再用 T = CDF_target⁻¹ ∘ CDF_input 建立映射。

§Octave 实例

gamma 与对数映射的数值对照

%% 03-gray-transform.m | 点运算：线性 / gamma / 对数映射
%% GNU Octave，零第三方依赖；合成图像，无需任何外部文件
clear; close all; clc;
SHOW = ~strcmp(getenv("IP_HEADLESS"), "1");
% ---- 参数区 ----
gamma = 0.45; a = 1.2; b = -0.1; N = 256;
% ---- 造图：偏暗的渐变 + 亮圆盘 ----
[X, Y] = meshgrid(1:N, 1:N);
f = 0.05 + 0.35 * (X / N) + 0.45*double((X-170).^2 + (Y-120).^2 < 45^2);
f = min(max(f, 0), 1);
% ---- 算法：四种 LUT 映射 ----
g_lin    = min(max(a*f + b, 0), 1);
g_gamma  = f .^ gamma;
g_invgan = f .^ (1/gamma);
g_log    = log(1 + f) / log(2);
r = linspace(0, 1, 256);
lut_gamma = r .^ gamma;
g_lut = reshape(interp1(r, lut_gamma, f(:)), size(f));   % 用查找表实现同一映射
% ---- 数值验证 ----
printf("原图       mean=%.4f std=%.4f\n", mean(f(:)), std(f(:)));
printf("线性拉伸   mean=%.4f std=%.4f\n", mean(g_lin(:)), std(g_lin(:)));
printf("gamma=%.2f  mean=%.4f std=%.4f\n", gamma, mean(g_gamma(:)), std(g_gamma(:)));
printf("gamma>1    mean=%.4f std=%.4f\n", mean(g_invgan(:)), std(g_invgan(:)));
printf("对数映射   mean=%.4f std=%.4f\n", mean(g_log(:)), std(g_log(:)));
printf("LUT 与逐像素映射最大差 = %.3e\n", max(abs(g_lut(:)-g_gamma(:))));
printf("f=0.25 时 gamma 输出 = %.4f (0.25^%.2f)\n", 0.25^gamma, gamma);
% ---- 可视化 ----
if SHOW
  figure("name", "03 灰度映射");
  subplot(2, 2, 1); imagesc(f, [0 1]); colormap gray; axis image off; title("原图（偏暗）");
  subplot(2, 2, 2); imagesc(g_gamma, [0 1]); axis image off; title("gamma<1 提亮暗部");
  subplot(2, 2, 3); imagesc(g_log, [0 1]); axis image off; title("对数压缩");
  subplot(2, 2, 4); plot(r, r.^gamma, "linewidth", 2); grid on; xlabel("输入 r"); ylabel("T(r)"); title("gamma LUT");
end

操作：运行后把 <code>gamma</code> 依次改成 0.25 / 1 / 2.2，记录均值与标准差的变化方向。　预期与判读：gamma&lt;1 时均值显著上升、标准差下降（暗部被抬起）；gamma&gt;1 时均值下降；LUT 与直接映射最大差接近 0；f=0.25、γ=0.45 时输出约 0.5359。　文件位置：part1/03-gray-transform/code/03-gray-transform.m

手写直方图均衡化与均匀性验证

%% 03-histeq.m | 直方图均衡化：统计 h -> CDF -> LUT -> 映射
%% GNU Octave，零第三方依赖；合成图像，无需任何外部文件
clear; close all; clc;
SHOW = ~strcmp(getenv("IP_HEADLESS"), "1");
% ---- 参数区 ----
bins = 256; N = 256;
% ---- 造图：窄动态范围的偏暗图 ----
[X, Y] = meshgrid(1:N, 1:N);
f = 0.30 + 0.20*(X/N) + 0.12*double((X-120).^2 + (Y-140).^2 < 50^2);
f = min(max(f, 0), 1);
% ---- 算法：直方图 -> 归一化 CDF -> 查表 ----
q = round(f(:) * (bins-1)) + 1;         % 量化到 1..bins
h = zeros(bins, 1);
for i = 1:numel(q)
  h(q(i)) = h(q(i)) + 1;               % 显式统计，便于对照公式
end
cdf = cumsum(h) / numel(q);
g = reshape(cdf(q), size(f));
% ---- 数值验证 ----
printf("直方图总和 = %d，像素总数 = %d\n", sum(h), numel(f));
printf("CDF 末项 = %.6f（应为 1）\n", cdf(end));
printf("原图 mean=%.4f std=%.4f  均衡后 mean=%.4f std=%.4f\n", ...
       mean(f(:)), std(f(:)), mean(g(:)), std(g(:)));
printf("原图占用的灰度级数 = %d / %d\n", sum(h > 0), bins);
hg = zeros(bins,1); qg = round(g(:)*(bins-1)) + 1;
for i = 1:numel(qg), hg(qg(i)) = hg(qg(i)) + 1; end
printf("均衡后占用的灰度级数 = %d / %d\n", sum(hg > 0), bins);
printf("理想均匀时每级像素数 = %.1f，实测最大级 = %d\n", numel(f)/bins, max(hg));
% ---- 可视化 ----
if SHOW
  figure("name", "03 直方图均衡");
  subplot(2, 2, 1); imagesc(f, [0 1]); colormap gray; axis image off; title("原图");
  subplot(2, 2, 2); imagesc(g, [0 1]); axis image off; title("均衡后");
  subplot(2, 2, 3); bar(h); xlim([0 bins]); title("原直方图");
  subplot(2, 2, 4); bar(hg); xlim([0 bins]); title("均衡后直方图");
end

操作：运行脚本，对照“原图占用级数”与“均衡后占用级数”；把 <code>bins</code> 改成 16 观察离散化变粗。　预期与判读：直方图总和等于像素数、CDF 末项为 1；原图只占约 80 个灰度级，均衡后覆盖范围显著变宽、均值趋近 0.5、标准差增大；由于同灰度像素必须成组搬移，直方图不会严格平坦。　文件位置：part1/03-gray-transform/code/03-histeq.m

代码块右上角可一键复制；本仓库 code/*.m 由 tools/extract_code.py 从这些代码块自动抽取，页面与脚本永远一致。脚本只用 Octave 核心函数，设 IP_HEADLESS=1 可跳过绘图。

§常见误区

  • 对 uint8 直接做 <code>f^γ</code>：指数运算会隐式转 double 但结果仍是 0～255 量纲，必须先归一化。
  • 以为均衡一定提升对比度：背景占比大时会放大噪声、导致主体过曝。
  • 把 CDF 当成 PDF 用：映射要用累积分布，不是直方图本身。
  • 忽略离散化：灰度级越少，均衡后越容易出现条带（banding）。
