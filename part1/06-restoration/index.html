§6.1退化模型与噪声

g(r,c) = (h ∗ f)(r,c) + n(r,c)　⇔　G = H·F + N

h 是 PSF（运动模糊是一条线、失焦是一个圆盘、大气湍流近似高斯）；n 是加性噪声。复原的目标是在只知道 g 与 h 的情况下估计 f，这是典型的反问题。

噪声模型典型来源 / 对策
高斯加性 N(0,σ²)传感器读出热噪声；均值/维纳/非局部均值
椒盐随机像素置 0/1传输误码、坏点；中值滤波
泊松方差随亮度增大光子散粒噪声；方差稳定化变换（Anscombe）
周期固定频率正弦干扰电源/扫描条纹；频域陷波

§6.2逆滤波与病态性

最朴素的想法是 F̂ = G / H。问题在于 H 在高频往往接近 0（PSF 是低通），而噪声 N 在高频并不小，于是 N/H 被急剧放大，结果被噪声淹没。这就是病态反问题：解不连续依赖输入，微小扰动导致巨大偏差。

判断标准：画出 |H| 的衰减曲线。凡是 |H| 低于噪声水平的频率，都不该做除法。第 06 章实验会让你亲手把 H 加一点保护再看差异。

§6.3维纳滤波

把“误差的均方期望最小”作为准则，假设图像与噪声是互不相关的平稳随机过程，可得频域解：

F̂(u,v) = [ H*(u,v) / ( |H(u,v)|² + Sₙ/S_f ) ] · G(u,v) = [ H* / (|H|² + K) ] · G
  • K = Sₙ/S_f 是噪信功率比；K = 0 退化为逆滤波，K → ∞ 退化为全零（完全不信数据）。
  • 在 |H|² ≫ K 的频率上近似逆滤波，在 |H|² ≪ K 的频率上自动衰减，从而抑制噪声放大。
  • 工程上 K 常当作可调标量：先扫几个数量级，用 PSNR 或下游任务指标选，而不是真的去估计功率谱。

维纳滤波是“最优线性复原”，但它仍假设平稳性与已知 PSF。真实场景（未知模糊核、空间变化噪声）需要盲去卷积或数据驱动的先验——这正是第 23 章深度复原网络要解决的问题。

§Octave 实例

模糊 + 噪声：逆滤波与维纳滤波的定量对照

%% 06-wiener.m | 退化模型 / 逆滤波 / 维纳滤波 / PSNR 对照
%% GNU Octave，零第三方依赖；合成图像，无需任何外部文件
clear; close all; clc;
SHOW = ~strcmp(getenv("IP_HEADLESS"), "1");
% ---- 参数区 ----
N = 128; psf_sigma = 1.4; noise_sigma = 0.02; K = 0.02; k = 9;
randn("seed", 41);
% ---- 造图：文字状方块 + 细线 ----
[X, Y] = meshgrid(1:N, 1:N);
f = 0.20 + 0.55*double(X > N/4 & X < 3*N/4 & Y > N/3 & Y < 2*N/3);
f(abs(Y - N/4) < 2) = 0.85;
% ---- 造 PSF：高斯核放入 NxN 左上角（DFT 周期原点）----
[PX, PY] = meshgrid(-(k-1)/2:(k-1)/2, -(k-1)/2:(k-1)/2);
psf = exp(-(PX.^2 + PY.^2) / (2*psf_sigma^2)); psf = psf / sum(psf(:));
P = zeros(N, N); P(1:k, 1:k) = psf;
H = fft2(P);
% ---- 退化：频域卷积 + 加性高斯噪声 ----
G = H .* fft2(f);
blurred = real(ifft2(G));
g = blurred + noise_sigma * randn(N, N);
G = fft2(g);
% ---- 复原 1：朴素逆滤波（加极小保护避免除零）----
f_inv = real(ifft2(G ./ (H + 1e-12)));
% ---- 复原 2：维纳滤波 ----
f_wie = real(ifft2(conj(H) ./ (abs(H).^2 + K) .* G));
% ---- 数值验证 ----
psnr_ = @(a,b) 10*log10(1 / max(mean((a(:)-b(:)).^2), eps));
printf("PSF 和 = %.6f, |H| 最小值 = %.6f（接近 0 的地方会放大噪声）\n", ...
       sum(psf(:)), min(abs(H(:))));
printf("PSNR: 模糊+噪声 %.2f dB -> 逆滤波 %.2f dB -> 维纳 %.2f dB\n", ...
       psnr_(g, f), psnr_(f_inv, f), psnr_(f_wie, f));
printf("逆滤波结果标准差 = %.4f（远大于原图 %.4f，说明噪声被放大）\n", ...
       std(f_inv(:)), std(f(:)));
printf("维纳结果标准差 = %.4f\n", std(f_wie(:)));
printf("提示：把 K 改成 0 / 0.001 / 0.2，看 PSNR 先升后降\n");
% ---- 可视化 ----
if SHOW
  figure("name", "06 维纳复原");
  subplot(2, 2, 1); imagesc(f, [0 1]); colormap gray; axis image off; title("原始 f");
  subplot(2, 2, 2); imagesc(g, [0 1]); axis image off; title("模糊 + 噪声 g");
  subplot(2, 2, 3); imagesc(f_inv); axis image off; title("逆滤波（噪声爆炸）");
  subplot(2, 2, 4); imagesc(f_wie, [0 1]); axis image off; title("维纳滤波");
end

操作：运行后按提示把 <code>K</code> 改成 0 / 0.001 / 0.2 各跑一次，记录 PSNR 曲线；再把 <code>noise_sigma</code> 提高 10 倍。　预期与判读：PSF 和为 1；<code>|H|</code> 最小值接近 0；逆滤波 PSNR 往往比退化图还差且标准差暴涨；维纳在合适 K 下明显改善；K 过大则过度平滑、PSNR 回落。　文件位置：part1/06-restoration/code/06-wiener.m

§常见误区

  • 用 <code>G./H</code> 且不检查 <code>|H|</code>：高频除零导致数值溢出或满屏噪声。
  • 把 <code>K</code> 当成固定常数：它应随噪声水平变化，不同图要重新扫参。
  • 用 PSNR 单独判定成功：过度平滑常给出不错的 PSNR，却丢失全部纹理。
  • 忽略边界：频域复原隐含周期卷积，边界会出现来自对侧的伪影。
