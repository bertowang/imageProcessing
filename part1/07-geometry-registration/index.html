§7.1变换矩阵与齐次坐标

用 2×2 矩阵无法表示平移。把点写成 [x,y,1]ᵀ，平移就可以和其他变换一样用矩阵乘法：

变换矩阵（3×3）自由度
平移[1 0 tₓ; 0 1 t_y; 0 0 1]2
旋转 + 缩放 + 剪切[a b 0; c d 0; 0 0 1]4～6
仿射线性部分任意 2×2 + 平移6
透视（单应）最后一行含 [p₁ p₂ 1]，再做归一化除法8

仿射保持平行性，透视不保持（所以文档矫正、车道线要用单应）。估计单应最少需要4 组不共线的点对应；多于 4 组时用最小二乘，并配合 RANSAC 剔除错误匹配。

§7.2反向映射与插值

把输入像素逐个搬到输出位置（前向映射）会出现两个问题：旋转后落点不是整数、且输出图上会留下空洞。正确做法是反向映射：遍历每个输出像素，用逆变换求它在输入图中的坐标，再插值取灰度。

[x_src, y_src, 1]ᵀ = T⁻¹ · [x_dst, y_dst, 1]ᵀ
插值做法效果 / 代价
最近邻取整到最近像素最快，保留原始灰度值，但有锯齿；适合标签图/掩模
双线性周围 4 点的距离加权平滑且常用，但会轻微模糊；不能用于整数标签图
双三次周围 16 点的三次卷积更锐利，可能出现过冲（灰度越界）

再次提醒坐标约定：矩阵索引是 (r,c)，几何坐标是 (x,y)=(c,r)。写 interp2(f, x_src, y_src) 时第一个查询坐标对应列。

§7.3配准流程

  1. 特征提取：角点/局部描述子（第 11 章）或直接利用像素强度。
  2. 匹配与剔错：最近邻距离比、RANSAC 求一致的最大内点集。
  3. 估计变换：用内点做最小二乘；医学/遥感还会用互信息作为相似度。
  4. 重采样：反向映射 + 插值生成配准图。
  5. 验证：叠加棋盘图、差分图、检查特征点残差。

失效模式主要是大位移、非刚性形变、跨模态（如 CT 与 MRI）、重复纹理。非刚性配准需要形变场与正则项，已超出线性变换范畴，下卷的光流/形变网络是常见解法。

§Octave 实例

旋转的反向映射：最近邻 vs 双线性

%% 07-affine-interp.m | 齐次坐标 / 反向映射 / 两种插值对比
%% GNU Octave，零第三方依赖；合成图像，无需任何外部文件
clear; close all; clc;
SHOW = ~strcmp(getenv("IP_HEADLESS"), "1");
% ---- 参数区 ----
N = 128; theta = pi/6;         % 旋转 30 度
% ---- 造图：棋盘 + 细线（便于观察锯齿）----
[X, Y] = meshgrid(1:N, 1:N);
f = double(mod(floor(X/16) + floor(Y/16), 2) == 0);
f = 0.15 + 0.7*f;
f(abs(Y - N/2) < 2) = 0.9;
% ---- 算法：输出坐标 -> 逆旋转 -> 输入坐标 ----
R = [cos(theta) -sin(theta); sin(theta) cos(theta)];
cx = N/2; cy = N/2;
x = X(:)' - cx; y = Y(:)' - cy;
src = R' * [x; y];                       % 逆变换（旋转矩阵的逆 = 转置）
sx = reshape(src(1,:), N, N) + cx;
sy = reshape(src(2,:), N, N) + cy;
inside = sx >= 1 & sx <= N & sy >= 1 & sy <= N;
g_near = interp2(f, sx, sy, "nearest", 0);
g_lin  = interp2(f, sx, sy, "linear", 0);
% ---- 数值验证 ----
printf("旋转角 = %.1f 度, 落在图内的输出像素比例 = %.4f\n", theta*180/pi, mean(inside(:)));
printf("原图唯一灰度级数 = %d, 双线性后 = %d（插值产生了中间灰度）\n", ...
       numel(unique(f(:))), numel(unique(round(g_lin(:)*1000))));
printf("最近邻 / 双线性 的均值 = %.4f / %.4f\n", mean(g_near(:)), mean(g_lin(:)));
printf("细线处灰度: 最近邻 %.3f ~ 双线性 %.3f\n", ...
       max(g_near(abs(Y-N/2)<3)), max(g_lin(abs(Y-N/2)<3)));
% ---- 可视化 ----
if SHOW
  figure("name", "07 反向映射");
  subplot(1, 3, 1); imagesc(f, [0 1]); colormap gray; axis image off; title("原图");
  subplot(1, 3, 2); imagesc(g_near, [0 1]); axis image off; title("最近邻（锯齿）");
  subplot(1, 3, 3); imagesc(g_lin, [0 1]); axis image off; title("双线性（平滑）");
end

操作：运行后把 <code>theta</code> 改成 0 验证输出与原图一致；改成 45° 观察四角黑色区域。　预期与判读：30° 旋转后约 70%～80% 的输出像素能找到输入；最近邻只产生原图已有的灰度级，双线性产生大量中间灰度；<code>interp2</code> 的第一个查询坐标是列（x），顺序写反会得到转置的错误结果。　文件位置：part1/07-geometry-registration/code/07-affine-interp.m

§常见误区

  • 把 (x,y) 写成 (r,c)：<code>interp2</code> 会给出镜像/转置的结果。
  • 对整数标签图（分割掩模）用双线性插值：会凭空造出不存在的类别编号。
  • 用前向映射画旋转：输出图上出现规律的空洞。
  • 透视变换忘记除以第三维齐次坐标，结果完全不对。

§习题与思考

  1. 推导旋转矩阵可逆且 <code>R⁻¹=Rᵀ</code>，说明为什么反向映射可以直接用转置。
  2. 把 <code>interp2</code> 的 <code>sx</code>/<code>sy</code> 交换，记录图像变化，并解释原因。
