§5.1二维 DFT 与频率坐标

二维离散傅里叶变换把 M×N 图像分解成不同方向、不同频率的复正弦：

F(u,v) = Σᵣ Σ꜀ f(r,c)·exp(−j2π(ur/M + vc/N))

fft2(f) 的输出把零频（直流）放在左上角；fftshift 把它搬到中心，低频靠中心、高频靠外圈，这样画出来的频谱才符合直觉。频谱幅度动态范围极大，显示时统一用 log(1+abs(F)) 压缩。

频域现象空域对应
中心亮点整体平均亮度（直流分量）
过中心的一条亮线图中垂直于该方向的条纹/边缘
能量集中在外圈噪声、细节、锐利边缘
周期性亮点周期性纹理，可用陷波滤波去除

§5.2频域滤波四步法

  1. F = fft2(f)（必要时先 fftshift 构造以中心为原点的 H，再 ifftshift 回去）。
  2. 构造与图像同尺寸的传递函数 H(u,v)，令 G = H .* F。
  3. g = real(ifft2(G))，取实部是因为数值误差会带来可忽略的虚部。
  4. 裁剪到 [0,1] 并评价。

三类低通滤波器（D(u,v) 是到频率中心的距离，D₀ 是截止频率）：

类型H(u,v)特点
理想D ≤ D₀ ? 1 : 0截止最陡，但空域冲激是 sinc，出现明显振铃
高斯exp(−D²/2D₀²)傅里叶变换仍是高斯，无振铃，过渡最缓
巴特沃斯1/(1+(D/D₀)^(2n))阶数 n 在陡峭度与振铃之间折中

高通可取 1 − H_low；带阻/陷波用于去除固定频率的周期干扰。注意 DFT 隐含周期假设，等价于 circular 边界填充，图像左右/上下亮度差大时会在边界产生条纹，可先做镜像填充或加窗。

§5.3相位比幅度更重要

把两幅图 f₁、f₂ 的 FFT 拆成幅度与相位，交换相位后反变换：重建结果看起来像提供相位的那张图，而不是提供幅度的那张。原因是相位编码了各频率分量的相对位置，边缘与结构正是这些分量对齐的结果；幅度只决定每个分量有多强。

这解释了为什么直方图相同 ≠ 图像相同：直方图只保留一阶幅度统计，完全丢弃位置信息。第 02 章埋的伏笔在这里闭合，也预告了下卷用感知损失/特征损失替代逐像素 MSE 的动机。

§Octave 实例

二维 FFT、高斯低通与能量保留比例

%% 05-fft-lowpass.m | fft2 / fftshift / 高斯低通 / 能量统计
%% GNU Octave，零第三方依赖；合成图像，无需任何外部文件
clear; close all; clc;
SHOW = ~strcmp(getenv("IP_HEADLESS"), "1");
% ---- 参数区 ----
N = 128; D0 = 18;
% ---- 造图：圆盘 + 竖直条纹 + 高斯噪声 ----
[X, Y] = meshgrid(1:N, 1:N);
f = 0.30 + 0.45*double((X-N/2).^2 + (Y-N/2).^2 < (N/5)^2);
f = f + 0.10*sin(2*pi*X/8);
f = min(max(f, 0), 1);
% ---- 算法 1：频谱与中心化 ----
F = fft2(f);
Fc = fftshift(F);
mag = log(1 + abs(Fc));
printf("F(1,1) = %.2f + %.2fi, 图像均值 = %.4f (直流/像素数)\n", ...
       real(F(1,1)), imag(F(1,1)), mean(f(:)));
printf("直流能量占比 = %.4f\n", abs(F(1,1))^2 / sum(abs(F(:)).^2));
% ---- 算法 2：高斯低通（以中心为原点构造 H）----
[U, V] = meshgrid(1:N, 1:N);
D = sqrt((U - N/2 - 1).^2 + (V - N/2 - 1).^2);
H = exp(-D.^2 / (2*D0^2));
g = real(ifft2(ifftshift(H) .* F));
% ---- 数值验证 ----
printf("H 中心值 = %.4f, H 角落值 = %.6f\n", H(N/2+1, N/2+1), H(1,1));
printf("滤波前后均值: %.4f -> %.4f (低通不改直流)\n", mean(f(:)), mean(g(:)));
printf("滤波前后标准差: %.4f -> %.4f (高频被衰减)\n", std(f(:)), std(g(:)));
printf("保留的频谱能量比例 = %.4f\n", sum(sum(abs(ifftshift(H).*F).^2)) / sum(abs(F(:)).^2));
printf("低通结果 MSE = %.6f, PSNR = %.2f dB\n", ...
       mean((f(:)-g(:)).^2), 10*log10(1/mean((f(:)-g(:)).^2)));
% ---- 可视化 ----
if SHOW
  figure("name", "05 频域低通");
  subplot(1, 3, 1); imagesc(f, [0 1]); colormap gray; axis image off; title("原图");
  subplot(1, 3, 2); imagesc(mag); axis image off; title("log 幅度谱（中心化）");
  subplot(1, 3, 3); imagesc(min(max(g,0),1), [0 1]); axis image off; title("高斯低通后");
end

操作：运行后把 <code>D0</code> 改成 5 / 40，观察“保留能量比例”与标准差；注意均值几乎不变。　预期与判读：<code>F(1,1)</code> 等于图像均值乘以像素数，虚部为 0；直流能量占绝大部分；低通前后均值相同、标准差下降；D₀ 越小保留能量越少、图像越糊。　文件位置：part1/05-frequency-domain/code/05-fft-lowpass.m

相位交换：结构由相位决定

%% 05-phase-swap.m | 交换两幅图的 FFT 相位，观察结构跟谁走
%% GNU Octave，零第三方依赖；合成图像，无需任何外部文件
clear; close all; clc;
SHOW = ~strcmp(getenv("IP_HEADLESS"), "1");
% ---- 参数区 ----
N = 128;
% ---- 造两幅统计相似、结构不同的图 ----
[X, Y] = meshgrid(1:N, 1:N);
f1 = 0.30 + 0.45*double((X-N/2).^2 + (Y-N/2).^2 < (N/5)^2);
f2 = 0.30 + 0.45*double(abs(X - Y) < N/10);
printf("两图均值差 = %.6f, 标准差差 = %.6f\n", ...
       abs(mean(f1(:))-mean(f2(:))), abs(std(f1(:))-std(f2(:))));
% ---- 算法：幅度 A / 相位 B 重组 ----
A = fft2(f1); B = fft2(f2);
r1 = real(ifft2(abs(A) .* exp(1i*angle(B))));   % f1 的幅度 + f2 的相位
r2 = real(ifft2(abs(B) .* exp(1i*angle(A))));   % f2 的幅度 + f1 的相位
% ---- 数值验证：自写相关系数（匿名函数），不依赖 statistics 包 ----
corr2_ = @(a,b) sum((a(:)-mean(a(:))).*(b(:)-mean(b(:)))) / ...
                sqrt(sum((a(:)-mean(a(:))).^2) * sum((b(:)-mean(b(:))).^2));
printf("重组图1 与 f1 相关 = %.4f, 与 f2 相关 = %.4f\n", corr2_(r1,f1), corr2_(r1,f2));
printf("重组图2 与 f1 相关 = %.4f, 与 f2 相关 = %.4f\n", corr2_(r2,f1), corr2_(r2,f2));
printf("结论：谁提供相位，重建图就更像谁（斜线 vs 圆盘）\n");
% ---- 可视化 ----
if SHOW
  figure("name", "05 相位交换");
  subplot(2, 2, 1); imagesc(f1, [0 1]); colormap gray; axis image off; title("f1 圆盘");
  subplot(2, 2, 2); imagesc(f2, [0 1]); axis image off; title("f2 斜带");
  subplot(2, 2, 3); imagesc(r1); axis image off; title("f1 幅度 + f2 相位");
  subplot(2, 2, 4); imagesc(r2); axis image off; title("f2 幅度 + f1 相位");
end

操作：运行脚本，看四个相关系数；再在图形窗口里确认重组图的结构跟相位走。　预期与判读：两图一阶统计几乎相同；<code>重组图1</code> 与 f2 的相关显著高于 f1，<code>重组图2</code> 反之。相位决定结构，幅度只决定对比度分布。　文件位置：part1/05-frequency-domain/code/05-phase-swap.m

§常见误区

  • 忘了 <code>fftshift</code> / <code>ifftshift</code> 配对，导致滤波器中心错位、结果整体偏移。
  • 直接显示 <code>abs(F)</code>：动态范围太大，除了直流点什么都看不见，要用 <code>log(1+abs(F))</code>。
  • 用理想低通追求“锐利截止”：空域会出现明显振铃，工程上优先用高斯或巴特沃斯。
  • 忘记 DFT 的周期假设：左右边界亮度差大时出现十字条纹。
